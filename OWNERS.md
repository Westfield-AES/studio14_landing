# Ownership map

Until GitHub organisation/team names are configured, role ownership is authoritative:

- Product/design: public copy, visual system and conversion journey.
- Web engineering: application code, static export, accessibility and performance.
- Security/privacy: headers, analytics/consent, legal links and supply-chain changes.

Before the first remote push, copy `.github/CODEOWNERS.example` to `.github/CODEOWNERS`, replace the placeholder with a GitHub user/team that has write access, and protect that file/default branch.
