# Contributing

Read `AGENTS.md`, the implementation phase status and relevant ADR/spec before changing code. Branch from `main`; use Conventional Commit subjects such as `feat(landing): add trust section`, `fix(a11y): restore focus order`, or `chore(deps): update locked packages`.

Keep each pull request to one reviewable outcome. Complete the PR template, run `pnpm check`, the browser/accessibility checks, and attach visual/performance evidence for user-facing work. Never commit credentials or unlicensed imagery.
