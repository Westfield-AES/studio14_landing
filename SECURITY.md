# Security policy

Do not disclose a suspected vulnerability in a public issue. Send a minimal report to `[SECURITY_EMAIL]` with the affected component, impact and safe reproduction steps; do not attach customer photographs, tokens or live credentials. Studio14 will acknowledge, triage and coordinate remediation/disclosure through the approved incident process.

Replace `[SECURITY_EMAIL]` with the monitored security address before the repository becomes public or any preview receives external traffic.
